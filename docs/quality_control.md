# 数据质量控制记录

## 2026-06-20: 低质量历史事件大清理

### 问题描述

数据库中存在约 36.6 万条低价值事件，这些事件：
- 不是具体的、有明确时间地点的历史事实
- 而是对人物的总结性评价、人生阶段标签或生硬模板生成的内容
- 例如："苏轼文学影响"、"苏轼壮年时期"、"苏轼代表作品"

### 删除标准

以下类型的事件被认定为**非事件**，不是针对**某个特定历史时间点发生的特定事情**的记录，全部删除：

|---|------|------|------|

| 2 | 文学/文化/历史影响 | 787 | "苏轼的文学影响" |
| 3 | 壮年时期 | 60,455 | "XXX·壮年时期：壮年时期的人生阅历" |

### 执行统计

- **删除前** published events: 891,033
- **删除后** published events: 525,240
- **删除总量**: 365,793 条（占 41.1%）
- **备份表**: `_deleted_event_backup`（便于恢复）
- **event_persons**: 通过 ON DELETE CASCADE 自动清理，从 ~900K 减少到 525,094

### 验证结果

所有 14 类低质量模板已全部清零：

✅ 重大成就 ✅ 文学影响 ✅ 壮年时期 ✅ 晚年时期 ✅ 童年时期  
✅ 历史遗产 ✅ 时代印记 ✅ 生平活动 ✅ 文学创作 ✅ 仕途任职  
✅ 代表作品(无具体名) ✅ 生活与活动 ✅ 时代背景 ✅ 评价式标题

### 前端配合修改

Timeline 组件相关：
- 轻量标签间距从 `pb-8`(32px) 调为 `pb-1.5`(6px)，避免连续标签时视觉重叠
- 正常事件卡片间距从 `pb-8` 调为 `pb-6`(24px)
- hover 时轻量标签增加 `z-10` 层叠，使用 `origin-left` 避免 transform 偏移
- 时间轴竖线在 hover 时变为琥珀色高亮

### 数据标准

此后生成的所有事件必须满足：
1. 描述的是一个**特定历史时间点发生的特定事情**
2. 不是对人物的总结性评价（"XXX是XX的代表人物"）
3. 不是"XX在某个时期做了XX类事情"的笼统总结
4. 不是纯模板填充（如"留下了属于这个时代的历史印记"）
5. 有具体的时间、地点、参与者、事件内容

### 恢复方法

如需恢复被删除的事件：
```sql
INSERT INTO events SELECT * FROM _deleted_event_backup;
UPDATE _deleted_event_backup SET id = CONCAT(id, '_backup');
```
