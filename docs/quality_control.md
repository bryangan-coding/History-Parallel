# 数据质量控制记录

## 2026-06-20: 低质量历史事件大清理

### 问题描述

数据库中存在约 30.5 万条低价值事件，这些事件：
- 不是具体的、有明确时间地点的历史事实
- 而是对人物的总结性评价、人生阶段标签或生硬模板生成的内容
- 例如："苏轼文学影响"、"苏轼壮年时期"、"苏轼代表作品"

### 删除标准

以下类型的事件被认定为**非事件**，不是针对**某个特定历史时间点发生的特定事情**的记录，全部删除：

| 类别 | 数量 | 说明 | 示例 |
|------|------|------|------|
| 重大成就 | 550 | 人物评价性总结 | "亚当·斯密的重大成就：苏格兰启蒙运动的思想领袖" |
| 文学/文化/历史影响 | 787 | 笼统的影响力评价 | "苏轼的文学影响" |
| 壮年时期 | 60,455 | 人生阶段标签 | "苏轼·壮年时期：壮年时期的人生阅历" |
| 晚年时期 | 60,455 | 人生阶段标签 | "苏轼·晚年时期：晚年时期的生活" |
| 童年/少年时期 | 60,455 | 人生阶段标签 | "XXX·童年时期" |
| 生平活动（生硬模板） | 50,475 | 无实质内容的生平事件 | "阿羅憾某的生平活动：在唐朝时期生活并参与社会活动" |
| 文学创作（生硬模板） | 1,819 | 笼统的创作描述 | "曹松的文学创作：从事文学创作，在唐代文坛产生影响" |
| 仕途/军事/政治活动 | 742 | 笼统的活动描述 | "安元暉的仕途任职：在唐朝各级政府中担任官职" |
| 代表作品（无具体作品名） | 1,136 | 说"他有很多代表作"但不说具体是哪部 | "苏轼代表作品" |
| 时代印记模板 | 60,478 | 纯模板生成，毫无信息量 | "XXX·时代印记：留下了属于这个时代的历史印记" |
| 生活与活动模板 | 38,932 | 纯模板生成 | "XXX的文学创作：在1900年至1977年间生活与活动" |
| 时代背景模板 | 379 | "XXX生活在XX时期"——纯背景介绍 | "曹芳与三国时期：曹芳生活在三国时期。三国（220—280年）" |
| XX——YY 评价式标题 | 49 | 人物评价当作事件标题 | "李白——诗仙"、"姜夔——清空骚雅" |

### 删除执行

```sql
DELETE e FROM events e
WHERE e.data_status = 'published' 
AND (
  -- 各类低价值模板
  e.title LIKE '%重大成就%'
  OR e.title LIKE '%文学影响%' OR e.title LIKE '%文化影响%' OR e.title LIKE '%历史影响%'
  OR e.title LIKE '%壮年时期%' OR e.title LIKE '%晚年时期%'
  OR e.title LIKE '%青年时期%' OR e.title LIKE '%童年时期%' OR e.title LIKE '%少年时期%'
  OR e.title LIKE '%的生平活动%'
  OR e.title LIKE '%的仕途任职%' OR e.title LIKE '%的军事活动%' OR e.title LIKE '%的政治活动%'
  OR e.title LIKE '%文学创作%'
  OR (e.title LIKE '%代表作品%' AND e.summary NOT LIKE '%《%》%')
  OR e.summary LIKE '%留下了属于这个时代的历史印记%'
  OR e.summary LIKE '%生活并参与社会活动%' OR e.summary LIKE '%间生活与活动%'
  OR (e.summary REGEXP '^[A-Za-z\\u4e00-\\u9fff]+生活在[A-Za-z\\u4e00-\\u9fff]+时期' AND e.title NOT LIKE '%生平%')
  OR (e.title LIKE '%——%' AND ... 排除出生/逝世/登基/即位/称帝等具体事件)
);
```

- **删除前** published events: 891,033
- **删除后** published events: 585,718
- **删除总量**: 305,315 条（占 34.3%）
- **备份表**: `_deleted_event_backup`（保留以备需要恢复）
- **event_persons**: 通过 ON DELETE CASCADE 自动清理

### 前端配合修改

- Timeline 组件中，轻量标签分类仍保留，但间距调整为 `pb-1.5`（6px），避免重叠
- 正常事件卡片间距调整为 `pb-6`（24px）
- hover 时轻量标签增加 `z-index` 层叠，使用 `origin-left` 避免 transform 偏移

### 数据标准

此后生成的所有事件必须满足以下标准：
1. 描述的是一个**特定历史时间点发生的特定事情**
2. 不是对人物的总结性评价
3. 不是"XX在某个时期做了XX类事情"的笼统总结
4. 不是纯模板填充（如"XXX留下了属于这个时代的历史印记"）
5. 有具体的时间、地点、参与者、事件内容

### 恢复方法

如需恢复删除的事件：
```sql
INSERT INTO events SELECT * FROM _deleted_event_backup;
DROP TABLE _deleted_event_backup;
```
