## 清理策略
1. 同一人物、同一年份的事件，如果描述同一主题，视为重复
2. 保留信息最完整、与权威来源（百度百科/维基百科）最一致的版本
3. 删除模板化生成的简略版本（`evt-lifespan-*`、`evt-struct*-*`、`evt-rich*-*`）
4. 仅当同一人物同年有其他更好的事件时才删除模板
